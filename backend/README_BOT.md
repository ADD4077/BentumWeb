# Telegram Bot для образовательной платформы Бентум

## Функционал

- **Привязка аккаунтов**: Пользователи могут привязать Telegram аккаунт к профилю на сайте
- **Поддержка**: Пересылка сообщений пользователей в службу поддержки
- **Уведомления**: Отправка важных уведомлений привязанным пользователям

## Установка и запуск

### 1. Настройка переменных окружения

Добавьте в `.env` файл:

```env
# Telegram Bot
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_support_chat_id
TELEGRAM_TOPIC_ID=9  # ID темы для поддержки (опционально)
```

### 2. Способы запуска

#### Способ 1: Management команда Django

```bash
cd backend
python manage.py run_telegram_bot
```

#### Способ 2: Отдельный скрипт

```bash
cd backend
python run_bot.py
```

#### Способ 3: Docker Compose

```bash
docker-compose -f docker-compose.bot.yml up -d
```

#### Способ 4: Встроенный запуск с основным приложением

При запуске через `entrypoint.sh` бот автоматически запустится в фоновом режиме, если настроен `TELEGRAM_BOT_TOKEN`.

### 3. Создание бота в Telegram

1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Имя бота: `Бентум Бот`
   - Username: `bentum_bot` (или другой уникальный)
4. Сохраните полученный токен в `TELEGRAM_BOT_TOKEN`

### 4. Настройка поддержки

1. Создайте группу для поддержки в Telegram
2. Добавьте бота в группу как администратора
3. Создайте тему (topic) для обращений в поддержку
4. Получите ID группы и темы и настройте в переменных окружения

## Команды бота

- `/start` - Приветствие и информация о боте
- `/start <token>` - Привязка аккаунта к профилю на сайте
- Любой другой текст - Отправка в службу поддержки

## Архитектура

### Основные файлы:

- `api/telegram_bot.py` - Основной класс бота с обработчиками
- `api/telegram_binding_service.py` - Сервис привязки аккаунтов
- `api/telegram_service.py` - Сервис отправки уведомлений
- `api/management/commands/run_telegram_bot.py` - Django management команда
- `run_bot.py` - Отдельный скрипт для запуска

### Процесс привязки:

1. Пользователь нажимает "Привязать Telegram" в настройках профиля
2. Генерируется уникальный токен и ссылка `https://t.me/bot_username?start=token`
3. Ссылка автоматически открывается в новой вкладке
4. Пользователь нажимает /start в Telegram
5. Бот обрабатывает токен и привязывает аккаунт
6. Пользователь видит подтверждение на сайте

## Логирование

Бот использует стандартное логирование Django. Уровень логирования можно настроить в `settings.py`:

```python
LOGGING = {
    'loggers': {
        'api.telegram_bot': {
            'handlers': ['console'],
            'level': 'INFO',
            'propagate': False,
        },
    },
}
```

## Тестирование

Для тестирования можно использовать тестовый токен бота или создать отдельного бота для разработки.

## Troubleshooting

### Проблема: "Bot token not configured"
**Решение**: Убедитесь, что `TELEGRAM_BOT_TOKEN` установлен в переменных окружения.

### Проблема: "Could not determine bot username"
**Решение**: Бот автоматически получит username из токена. Если ошибка persists, проверьте валидность токена.

### Проблема: Бот не отвечает на команды
**Решение**: Проверьте, что бот запущен и имеет доступ к базе данных.

### Проблема: Сообщения не доходят до поддержки
**Решение**: Убедитесь, что `TELEGRAM_CHAT_ID` и `TELEGRAM_TOPIC_ID` настроены правильно и бот добавлен в группу с правами администратора.
