# 🤖 Настройка Telegram бота для поддержки

## 📋 Что нужно сделать

### 1. Создание Telegram бота

1. **Найдите @BotFather** в Telegram
2. **Отправьте команду**: `/start`
3. **Создайте бота**: `/newbot`
4. **Введите имя бота**: `BentumWeb Support Bot`
5. **Введите username**: `bentumweb_support_bot`
6. **Скопируйте токен** - он выглядит так: `1234567890:ABCDEF...`

### 2. Создание канала с темами для уведомлений

1. **Создайте новый канал** в Telegram
2. **Сделайте его приватным** или публичным
3. **Включите темы** в настройках канала (если еще не включены)
4. **Создайте тему** для заявок поддержки:
   - Нажмите на канал → "Управление каналом" → "Темы"
   - Создайте новую тему с названием "Поддержка" или "Заявки"
   - **Запомните ID темы** (обычно начинается с 1, 2, 3...)
5. **Добавьте бота** как администратора с правом на отправку сообщений
6. **Получите ID канала**:
   - Для публичного: `@channel_name`
   - Для приватного: отправьте сообщение в канал и перейдите по ссылке:
     ```
     https://api.telegram.org/bot<TOKEN>/getUpdates
     ```
   - Найдите `chat.id` в ответе (обычно отрицательное число)
7. **Определите ID темы**:
   - Отправьте тестовое сообщение в нужную тему
   - Посмотрите в `getUpdates` поле `message_thread_id`

### 3. Настройка Django

Откройте файл `backend/backend/settings.py` и замените:

```python
# Telegram Bot settings
TELEGRAM_BOT_TOKEN = 'YOUR_BOT_TOKEN_HERE'  # Замените на токен вашего бота
TELEGRAM_CHAT_ID = 'YOUR_CHAT_ID_HERE'      # Замените на ID вашего канала/чата
```

На ваши реальные значения:

```python
# Telegram Bot settings
TELEGRAM_BOT_TOKEN = '1234567890:ABCDEF...'  # Ваш токен
TELEGRAM_CHAT_ID = '-1001234567890'          # ID вашего канала
TELEGRAM_TOPIC_ID = 9                        # ID темы для заявок поддержки
TELEGRAM_NEW_USERS_TOPIC_ID = 3              # ID темы для уведомлений о новых пользователях
```

### 4. Проверка работы

Перезапустите Django сервер и проверьте:

```bash
# Тест соединения для заявок поддержки (только в DEBUG режиме)
curl http://localhost:8000/api/support/test

# Тест соединения для уведомлений о новых пользователях (только в DEBUG режиме)
curl http://localhost:8000/api/support/test-user-notification
```

Или через браузер: 
- `http://localhost:8000/api/support/test`
- `http://localhost:8000/api/support/test-user-notification`

## 🎯 Как это работает

### 📬 Заявки в поддержку
1. **Пользователь** открывает форму поддержки
2. **Выбирает тип** обращения (поддержка, ошибка, предложение, вопрос)
3. **Пишет сообщение** и нажимает "Отправить в Telegram"
4. **Сервер** форматирует сообщение с данными пользователя
5. **Бот отправляет сообщение** в тему с ID 9
6. **Вы получаете** уведомление в теме поддержки

### 👤 Уведомления о новых пользователях
1. **Новый пользователь** авторизуется в системе
2. **Система создает** запись в базе данных
3. **Автоматически отправляется** уведомление в тему с ID 3
4. **Вы получаете** полную информацию о новом пользователе

## 🔧 Возможные проблемы

### ❌ "Bot token not configured"
**Решение**: Проверьте что `TELEGRAM_BOT_TOKEN` правильно указан в settings.py

### ❌ "Chat ID not configured" 
**Решение**: Проверьте что `TELEGRAM_CHAT_ID` правильно указан в settings.py

### ❌ "Forbidden: bot was kicked from the chat"
**Решение**: Добавьте бота обратно в канал и дайте права на отправку сообщений

### ❌ "Bad Request: chat not found"
**Решение**: Проверьте правильность ID канала, убедитесь что бот в нем состоит

### ❌ "Bad Request: message thread not found"
**Решение**: Проверьте правильность ID темы, убедитесь что тема существует в канале

### ❌ "Forbidden: bot is not a member of the channel chat"
**Решение**: Добавьте бота в канал и дайте права на отправку сообщений

### ❌ "Forbidden: bot can't send messages to this topic"
**Решение**: Убедитесь что бот имеет права на отправку сообщений в эту тему
