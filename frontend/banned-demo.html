Как это работает?

Важно: Убедитесь что приложение запущено! Откройте терминал в папке frontend и выполните: npm run dev или yarn dev

При нажатии "Заблокировать пользователя" в localStorage сохраняются данные с признаком бана. При загрузке приложения проверяется статус пользователя, и если он заблокирован, показывается страница бана вместо основного контента.

Новая функция: При нажатии "Открыть профиль" открывается модальное окно профиля поверх страницы бана. Теперь кнопка "Выйти из аккаунта" в профиле работает правильно - очищает все данные и перезагружает страницу на главную.

🔄 Синхронизация: Кнопка "Перейти к приложению" автоматически передает статус бана и данные пользователя в запущенное приложение через URL параметры.
