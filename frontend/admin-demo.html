Как это работает?

Важно: Убедитесь что приложение запущено! Откройте терминал в папке frontend и выполните: npm run dev или yarn dev

Права администратора: Пользователь считается администратором если: email содержит 'admin', ID равен 1, или имя содержит 'Admin'.

🛡️ Защита от бана: Администраторы НЕ МОГУТ быть забанены! Даже если их данные есть в списке заблокированных, система всегда будет показывать им основное приложение, а не страницу бана.

Функции админки: Бан/разбан пользователей, просмотр профилей, статистика пользователей. Кнопка бана администраторов скрыта и заменена иконкой щита.

Как попасть в админку: Есть 2 способа: 1) Войти как администратор через кнопку "🔐 Войти как администратор" 2) Если вы уже вошли как обычный пользователь, нажмите "👑 Сделать меня админом"

🔄 Синхронизация: Кнопка "Перейти к приложению" автоматически передает данные пользователя (админ права, бан статус) в запущенное приложение через URL параметры.
